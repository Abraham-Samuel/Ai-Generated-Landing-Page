# TaskFlow Landing Page

## Project Overview

TaskFlow is a responsive Task Management SaaS landing page built using HTML and CSS. It showcases a modern UI for a productivity platform that helps users manage tasks, collaborate with teams, and track progress efficiently.

---

## Features Implemented

* Responsive landing page design
* Semantic HTML5 structure
* Sticky navigation bar
* Hero section with CTA buttons
* Features section using CSS Grid
* Pricing section layout
* Call-To-Action (CTA) section
* Footer section
* Hover animations on cards and buttons
* Flexbox and Grid layout system
* Accessibility improvements (ARIA labels, alt text)
* Mobile responsiveness using media queries

---

## Tech Stack

* HTML5
* CSS3 (Flexbox + Grid)

The layout adapts to different screen sizes using CSS media queries:

* Desktop: multi-column grid layout
* Mobile: stacked single-column layout
